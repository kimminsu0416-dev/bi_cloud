# 🚀 AI 뉴스 큐레이션 인텔리전스 (AI News Intelligence & Curation)

엔터프라이즈 클라우드, 가상화(VDI/DaaS), 망분리 및 제로트러스트 보안 분야의 최신 뉴스를 네이버 검색 API로 자동 수집하고, **Google Gemini 2.5 AI**가 사용자 맞춤 관점(필터링 프롬프트)을 반영하여 **핵심 3줄 요약 및 비즈니스 시사점**을 도출하는 프리미엄 큐레이션 서비스입니다.

---

## 🌟 주요 핵심 기능

1. **사전 정의된 타겟 키워드 관리 (추가/삭제/초기화)**:
   - 우측 상단 **[키워드 관리]** 설정 창을 통해 새로운 관심 키워드를 추가하거나 불필요한 키워드를 삭제 가능
   - 언제든지 원클릭으로 기본 23개 키워드로 초기화/복원 지원
   - 메인 화면에서 등록된 키워드들을 칩 형태로 개별 선택/해제 및 일괄 검색 가능
2. **정밀한 검색 기간 설정 (Date Range)**:
   - **전체 (최신순)**
   - **최근 3일**
   - **최근 1주일**
   - **최근 2주일**
   - **최근 1개월**
   - **📅 달력 직접 날짜 지정**: 시작일과 종료일을 직접 선택하여 원하는 기간 내 기사만 수집
3. **새로운 키워드 즉시 입력 검색**:
   - 쉼표(`,`) 또는 줄바꿈으로 원하는 키워드를 자유롭게 입력하여 검색
4. **AI 맞춤형 필터링 프롬프트**:
   - "보안 취약점 위주", "신제품 및 수주 계약 위주", "임원진 전략 보고용" 등 사용자가 입력한 필터링 지침에 따라 AI 요약 관점 실시간 조정
5. **네이버 최신 뉴스 수집 & 원문 바로가기 링크**:
   - 지정된 기간 내 기사 2건(설정 가능)을 수집하고 각 요약 카드 하단에 원문 링크 버튼 제공
6. **경영진 보고용 원클릭 복사**:
   - 큐레이션된 전체 분석 결과를 마크다운/텍스트 보고서 형식으로 클립보드에 원클릭 복사

## 🛠️ 실행 및 환경 설정 가이드

### 1. 환경 변수 설정 (`.env`)
프로젝트 루트의 `.env` 파일에 API Key를 입력합니다:

```env
# Google Gemini API Key (무료 발급: https://aistudio.google.com/app/apikey)
GEMINI_API_KEY=your_gemini_api_key

# Naver Search API Key (발급: https://developers.naver.com/apps/#/register)
NAVER_CLIENT_ID=your_naver_client_id
NAVER_CLIENT_SECRET=your_naver_client_secret
```

### 2. 서버 실행 (`uv run` 필수)

```bash
# Django 서버 실행
uv run python manage.py runserver
```

브라우저에서 **`http://127.0.0.1:8000`** 으로 접속하여 바로 서비스를 이용하실 수 있습니다.
